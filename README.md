## AegisGuard v1.2.5

AegisGuard is a **modern, Folia-optimized land protection and economy ecosystem** for Minecraft servers (Spigot/Paper/Purpur/Folia).
It doesn’t just lock chunks. It turns land into a **living asset**: progression, governance, safety nets, and an economy loop designed for long-running worlds.

**Core pillars**
- **Protection-first**: claims as sanctuaries with intelligent border behavior
- **Progression-driven**: leveling, petitions, and guided expansion
- **Economy-ready**: ClaimBlocks economy + Vault exchange
- **Admin-grade controls**: server zones, staff tools, migration imports
- **Localization system**: per-language packs with sane fallbacks
